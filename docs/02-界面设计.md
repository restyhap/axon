# Axon 界面设计

## 一、布局架构

Axon 有两种顶层布局，根据当前视图模式切换：

```
Layout (全局布局)
├── MainLayout        ← 文档视图 / 脑图视图 共用
└── ShowcaseLayout    ← 演示视图 独占
```

---

## 二、组件树

### 2.1 MainLayout（文档 & 脑图视图）

```
MainLayout
├── TitleBar                          # 标题栏（固定顶部）
│   ├── Title                         # 应用标题 / 当前文件名
│   ├── ButtonGroup                   # 视图切换按钮组
│   │   ├── [文档] 按钮
│   │   ├── [脑图] 按钮
│   │   └── [演示] 按钮
│   ├── SeparatorLine                 # 标题栏与内容区的分隔线
│   └── TabGroup                      # 标签组（多文档标签页）
│       ├── Tab × N                   # 已打开的文档标签
│       └── OverflowDropdown          # 超出宽度时的下拉菜单
│
└── Hero                              # 英雄区（标题栏以下的全部区域）
    ├── NavigationPanel               # 左侧导航面板（可变内容）
    │   ├── [文档模式] → MarkdownView # 左 = 目录栏 + 中 = 文档预览
    │   └── [脑图模式] → MindmapView  # 左 = 脑图画布
    │
    ├── ResizableDivider              # 可拖拽分隔线
    │
    └── EditorPanel                   # 右侧编辑面板（始终可见）
        └── TiptapEditor              # 所见即所得 Markdown 编辑器
```

### 2.2 ShowcaseLayout（演示视图）

```
ShowcaseLayout
├── TitleBar                          # 标题栏（精简版）
│   ├── Title
│   ├── ButtonGroup                   # 视图切换按钮组（保留，可退出演示）
│   │   ├── [文档] 按钮
│   │   ├── [脑图] 按钮
│   │   └── [演示] 按钮（高亮）
│   └── SeparatorLine
│   （注意：TabGroup 在演示模式下隐藏）
│
└── ShowcaseView                      # 全屏演示区域
    └── RevealPresentation            # reveal.js 幻灯片
```

## 三、三种视图的布局对比

### 3.1 文档视图

```
┌─────────────────────────────────────────────────────┐
│ TitleBar: [Title] [文档|脑图|演示] ─── [Tab1][Tab2] │
├──────────┬──────────────┬───┬────────────────────────┤
│          │              │ ↔ │                        │
│  目录栏   │   文档预览    │ ↔ │   Markdown 编辑器      │
│  (TOC)   │  (Rendered)  │ ↔ │   (Tiptap WYSIWYG)    │
│          │              │ ↔ │                        │
├──────────┴──────────────┤   │                        │
│    NavigationPanel      │   │     EditorPanel        │
└─────────────────────────┴───┴────────────────────────┘
```

- 左侧 NavigationPanel 内部分为**目录栏**和**文档预览**两部分
- 右侧 EditorPanel 为所见即所得编辑器
- 中间 ResizableDivider 可左右拖拽

### 3.2 脑图视图

```
┌─────────────────────────────────────────────────────┐
│ TitleBar: [Title] [文档|脑图|演示] ─── [Tab1][Tab2] │
├─────────────────────────┬───┬────────────────────────┤
│                         │ ↔ │                        │
│                         │ ↔ │                        │
│      脑图画布            │ ↔ │   Markdown 编辑器      │
│    (Markmap / Flow)     │ ↔ │   (Tiptap WYSIWYG)    │
│                         │ ↔ │                        │
│                         │ ↔ │                        │
│    NavigationPanel      │   │     EditorPanel        │
└─────────────────────────┴───┴────────────────────────┘
```

- 左侧 NavigationPanel 整体变为脑图画布
- 右侧 EditorPanel 不变，编辑器始终可见
- **关键**：文档视图的「目录+预览」和脑图视图的「脑图画布」共用同一个 NavigationPanel 容器

### 3.3 演示视图

```
┌─────────────────────────────────────────────────────┐
│ TitleBar: [Title] [文档|脑图|演示]                   │
├─────────────────────────────────────────────────────┤
│                                                     │
│                                                     │
│              全屏幻灯片演示                           │
│            (reveal.js)                              │
│                                                     │
│                                                     │
│                  ShowcaseView                        │
└─────────────────────────────────────────────────────┘
```

- TabGroup 隐藏
- 标题栏下方整个区域为全屏演示
- 保留视图切换按钮，方便退出演示模式

## 四、视图切换逻辑

```
点击 [文档] 按钮 → MainLayout + NavigationPanel 显示 MarkdownView
点击 [脑图] 按钮 → MainLayout + NavigationPanel 显示 MindmapView
点击 [演示] 按钮 → 切换为 ShowcaseLayout
```

**核心要点**：
- 文档 ↔ 脑图 切换时，只有 NavigationPanel 内部内容变化，EditorPanel 不动，无闪烁
- 切换到演示时，整个布局替换为 ShowcaseLayout

## 五、可拖拽分隔线 (ResizableDivider)

### 5.1 行为规则

| 属性 | 值 |
|------|-----|
| 拖拽方向 | 水平（左右） |
| 最大宽度（左侧） | 整体宽度的 50% |
| 最小宽度（左侧） | 能完整显示 TitleBar 中 Title + ButtonGroup 的宽度（动态计算） |
| 默认比例 | 左 50% : 右 50% |
| 拖拽时 | 实时调整两侧宽度，内容自适应 |
| 记忆 | 用户拖拽后的比例通过 tauri-plugin-store 持久化 |

### 5.2 最小宽度计算

```typescript
// 最小宽度 = Title 宽度 + ButtonGroup 宽度 + 间距
const minLeftWidth = titleRef.width + buttonGroupRef.width + PADDING;
```

## 六、标签组 (TabGroup)

### 6.1 行为规则

| 功能 | 说明 |
|------|------|
| 显示 | 每个打开的文档一个标签 |
| 激活 | 点击标签切换到对应文档 |
| 关闭 | 标签上的关闭按钮，未保存时提示 |
| 溢出 | 标签超出可视宽度时，右侧出现下拉按钮，展示所有标签列表 |
| 隐藏 | 演示视图下 TabGroup 整体隐藏 |

## 七、组件与目录映射

```
src/
├── components/
│   ├── layout/                       # 布局组件（页面骨架）
│   │   ├── Layout.tsx                # 全局布局，根据 viewMode 切换 Main/Showcase
│   │   ├── MainLayout.tsx            # 文档/脑图共用布局
│   │   ├── ShowcaseLayout.tsx        # 演示布局
│   │   ├── Hero.tsx                  # 英雄区容器
│   │   ├── NavigationPanel.tsx       # 左侧导航面板
│   │   └── EditorPanel.tsx           # 右侧编辑面板
│   │
│   ├── common/                       # 通用组件（跨模块复用）
│   │   ├── TitleBar.tsx              # 标题栏
│   │   ├── ButtonGroup.tsx           # 视图切换按钮组
│   │   ├── TabGroup.tsx              # 标签组
│   │   ├── ResizableDivider.tsx      # 可拖拽分隔线
│   │   └── SeparatorLine.tsx         # 分隔线
│   │
│   └── ui/                           # shadcn/ui 基础组件（自动生成）
│       ├── button.tsx
│       ├── dropdown-menu.tsx
│       └── ...
│
├── features/                         # 业务功能模块
│   ├── editor/                       # Markdown 编辑器
│   │   └── components/
│   │       └── TiptapEditor.tsx      # Tiptap 编辑器组件
│   ├── mindmap/                      # 思维导图
│   │   └── components/
│   │       └── MarkmapView.tsx       # markmap 渲染组件
│   ├── presentation/                 # 演示文稿
│   │   └── components/
│   │       └── RevealPresentation.tsx # reveal.js 渲染组件
│   └── knowledge-base/              # 知识库管理
│       └── components/
│           └── KBBrowser.tsx         # 知识库浏览器组件
```

**分类原则**：
| 目录 | 职责 | 判断标准 |
|------|------|---------|
| `components/layout/` | 布局骨架 | 决定页面结构和区域划分，不含业务逻辑 |
| `components/common/` | 通用交互组件 | 被多个布局或功能模块复用 |
| `components/ui/` | 原子级 UI 组件 | shadcn/ui 生成，不手动修改 |
| `features/*/components/` | 业务组件 | 只属于某个功能模块，包含业务逻辑 |
