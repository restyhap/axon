# Axon 界面设计

## 一、布局架构

Axon 采用统一的左中右布局结构，根据当前视图模式切换右侧内容：

```
Layout (全局布局)
└── AppLayout          ← 所有视图共用，左中右布局
    ├── LeftPanel        ← 左侧面板（标题栏）
    ├── Divider         ← 中间分割线（可拖拽）
    └── RightPanel       ← 右侧面板（主内容区）
```

## 二、组件树

### 2.1 AppLayout（统一布局）

```
AppLayout
├── LeftPanel                        # 左侧面板（固定宽度）
│   ├── AppTitle                    # 应用标题 "Axon"
│   ├── ViewModeGroup               # 视图模式切换组
│   │   ├── [文档] 按钮
│   │   ├── [脑图] 按钮
│   │   └── [演示] 按钮
│   ├── ThemeToggle                # 主题切换按钮
│   ├── DocumentTabs               # 文档标签组（多文档标签页）
│   │   ├── Tab × N              # 已打开的文档标签
│   │   └── OverflowDropdown     # 超出宽度时的下拉菜单
│   └── StatusBar                # 状态栏（文件名、保存状态等）
│
├── Divider                         # 可拖拽分割线
│   └── Handle                    # 拖拽手柄
│
└── RightPanel                      # 右侧面板（可变内容）
    ├── EditorView                 # 文档视图（可拖拽左右分栏）
    │   ├── NavigationPanel        # 左侧导航面板
    │   │   ├── [文档模式] → TOC + Preview
    │   │   └── [脑图模式] → MindmapCanvas
    │   ├── InnerDivider         # 内部可拖拽分割线
    │   └── EditorPanel          # 右侧编辑面板
    │       └── TiptapEditor     # 所见即所得 Markdown 编辑器
    │
    ├── MindmapView              # 脑图视图（全屏脑图画布）
    │   └── MindmapCanvas       # markmap / Flow 画布
    │
    └── PresentationView         # 演示视图（全屏幻灯片）
        └── RevealSlides        # reveal.js 幻灯片
```

## 四、视图切换逻辑

```
点击 [文档] 按钮 → RightPanel 显示 EditorView（可拖拽布局）
点击 [脑图] 按钮 → RightPanel 显示 MindmapView（全屏脑图）
点击 [演示] 按钮 → RightPanel 显示 PresentationView（全屏幻灯片）
```

**核心要点**：
- 左侧面板始终不变，包含所有全局控制元素
- 右侧面板根据视图模式切换内容
- 文档视图内部还有可拖拽分割线，其他视图为全屏显示

## 五、可拖拽分割线 (Divider)

### 5.1 主分割线（左中右布局）

| 属性 | 值 |
|------|-----|
| 拖拽方向 | 水平（左右） |
| 最小宽度（左侧） | 250px（能完整显示标题栏内容） |
| 最大宽度（左侧） | 400px（避免占用过多空间） |
| 默认宽度 | 300px |
| 拖拽时 | 实时调整左侧面板宽度，右侧自适应 |
| 记忆 | 用户拖拽后的宽度通过 Zustand 持久化 |

### 5.2 内部分割线（文档视图）

| 属性 | 值 |
|------|-----|
| 拖拽方向 | 水平（左右） |
| 最小宽度（左侧） | 200px |
| 最大宽度（左侧） | 右侧面板宽度的 50% |
| 默认比例 | 左 40% : 右 60% |
| 拖拽时 | 实时调整两侧宽度，内容自适应 |
| 记忆 | 用户拖拽后的比例通过 Zustand 持久化 |

## 六、文档标签组 (DocumentTabs)

### 6.1 行为规则

| 功能 | 说明 |
|------|------|
| 显示 | 每个打开的文档一个标签 |
| 激活 | 点击标签切换到对应文档 |
| 关闭 | 标签上的关闭按钮，未保存时提示 |
| 溢出 | 标签超出可视宽度时，右侧出现下拉按钮，展示所有标签列表 |
| 位置 | 左侧面板中部，在视图切换按钮下方 |

## 七、组件与目录映射

```
src/
├── components/
│   ├── layout/                       # 布局组件（页面骨架）
│   │   ├── AppLayout.tsx             # 全局布局，左中右结构
│   │   ├── LeftPanel.tsx             # 左侧面板（标题栏）
│   │   ├── RightPanel.tsx            # 右侧面板（主内容区）
│   │   └── Divider.tsx              # 可拖拽分割线
│   │
│   ├── common/                       # 通用组件（跨模块复用）
│   │   ├── AppTitle.tsx             # 应用标题
│   │   ├── ViewModeGroup.tsx        # 视图模式切换组
│   │   ├── ThemeToggle.tsx          # 主题切换按钮
│   │   ├── DocumentTabs.tsx         # 文档标签组
│   │   ├── StatusBar.tsx            # 状态栏
│   │   └── InnerDivider.tsx        # 内部可拖拽分割线
│   │
│   └── ui/                           # shadcn/ui 基础组件（自动生成）
│       ├── button.tsx
│       ├── dropdown-menu.tsx
│       └── ...
│
├── features/                         # 业务功能模块
│   ├── editor/                       # Markdown 编辑器
│   │   ├── EditorView.tsx           # 文档视图容器
│   │   └── components/
│   │       ├── NavigationPanel.tsx   # 左侧导航面板
│   │       ├── TOCPanel.tsx         # 目录栏
│   │       ├── PreviewPanel.tsx      # 文档预览
│   │       └── TiptapEditor.tsx    # Tiptap 编辑器组件
│   ├── mindmap/                      # 思维导图
│   │   ├── MindmapView.tsx          # 脑图视图容器
│   │   └── components/
│   │       └── MindmapCanvas.tsx    # markmap 渲染组件
│   └── presentation/                 # 演示文稿
│       ├── PresentationView.tsx      # 演示视图容器
│       └── components/
│           └── RevealSlides.tsx      # reveal.js 渲染组件
```

**分类原则**：
| 目录 | 职责 | 判断标准 |
|------|------|---------|
| `components/layout/` | 布局骨架 | 决定页面结构和区域划分，不含业务逻辑 |
| `components/common/` | 通用交互组件 | 被多个布局或功能模块复用 |
| `components/ui/` | 原子级 UI 组件 | shadcn/ui 生成，不手动修改 |
| `features/*/` | 业务功能模块 | 包含业务逻辑和特定视图实现 |

## 八、布局实现细节

  layoutId="app"

- **移动端**：左侧面板隐藏，通过抽屉访问

## 九、交互流程

### 9.1 新建文档流程

1. 点击左侧面板的"新建文档"按钮
2. 在文档标签组中添加新标签
3. 右侧面板显示编辑器，焦点在编辑器
4. 自动保存草稿到本地存储

### 9.2 切换视图流程

1. 点击左侧面板的视图切换按钮
2. 右侧面板内容切换，左侧面板保持不变
3. 如果是文档视图，内部布局保持用户上次拖拽的比例
4. 状态栏更新当前视图信息

### 9.3 拖拽调整流程

1. 用户拖拽主分割线，调整左侧面板宽度
2. 实时更新布局，右侧面板自适应
3. 拖拽结束后，保存宽度到 Zustand store
4. 文档视图的内部拖拽同理，保存内部比例

## 十、设计原则

1. **一致性**：所有视图共享左侧面板，保持全局控制的一致性
2. **灵活性**：文档视图内部可二次拖拽，其他视图全屏显示
3. **效率性**：常用操作集中在左侧面板，减少鼠标移动距离
4. **可扩展性**：布局结构清晰，易于添加新的视图模式
5. **响应式**：支持不同屏幕尺寸，提供最佳用户体验
