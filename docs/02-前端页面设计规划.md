## 2) 提炼后的 PC 端设计规范基础框架（可直接指导开发）

### 2.1 适用范围与目标

- 适用终端：桌面端（窗口宽度 1024px–1920px，含可缩放窗口）
- 设计目标：高信息密度但不拥挤；层级清晰；键盘可达；WCAG 2.1/2.2 AA 核心要求达标
- 落地方式：以“设计 token”为唯一可信来源（source of truth），并映射为 CSS 自定义属性

### 2.2 断点（Breakpoints）与布局策略

本规范以“桌面优先 + 向下优雅降级”为主。断点只用于重排（reflow）与密度（density）调整，不用于“每像素适配”。

| 语义断点 | 窗口宽度（px） | 主要变化 | 目标 |
|---|---:|---|---|
| Desktop-XL | ≥1680 | 更大容器、更多留白、可增加分栏 | 强阅读舒适度与视觉呼吸 |
| Desktop-L | 1440–1679 | 标准密度、常用工作区宽度 | 主力规格 |
| Desktop-M | 1280–1439 | 适度收紧 gutter/边距 | 保持信息密度与可读性 |
| Desktop-S | 1024–1279 | 更紧凑间距、减少并排列数 | 不出现横向滚动、保持可操作性 |

**响应式适配策略（优先级）**

1. Reflow：列从 3→2→1，侧栏从常驻→可折叠→抽屉化（如果有）。
2. Resize：容器 max-width、gutter、外边距按断点调整；字号使用 fluid（clamp/线性插值）在范围内微调。
3. Show/Hide：只对“次要信息”做折叠（例如 secondary metadata、辅助面板），核心任务信息不隐藏。

### 2.3 栅格系统（Grid System）

**基础规则**

- 列数：12 columns（PC 端通用，易拆分 2/3/4/6）
- gutter：断点内固定（Desktop-XL/L 24px，M 20px，S 16px）
- page margin（内容区外边距）：Desktop-XL 32px，L/M 24px，S 16px
- container max-width：Desktop-XL 1600px，L 1360px，M 1200px，S 960px

**布局建议（可直接用于设计稿标注）**

- 主内容区域：优先使用 8–9 列
- 右侧信息面板：优先 3–4 列（1280 以下建议折叠/收起）
- 复杂页面：使用“模块化网格”（模块以 4px spacing + 12 列组合）

### 2.4 字体与排版（Typography）

**字体族**

- Sans：`ui-sans-serif, system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", Arial, "Noto Sans"`
- Mono（代码/标注）：`ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, "Liberation Mono", "Courier New"`

**字号层级（Desktop-S → Desktop-XL 的 fluid 区间）**

| 语义层级 | 用途 | 字号 token（px） | 行高 |
|---|---|---:|---:|
| H1 | 页面标题/主视图标题 | 28 → 34 | 1.2 |
| H2 | 区块标题 | 22 → 24 | 1.35 |
| H3 | 小标题/卡片标题 | 18 → 20 | 1.35 |
| Body | 正文/表单/列表 | 14 → 16 | 1.55 |
| Small | 辅助信息/注释 | 12 → 13 | 1.55 |

**可读性规则**

- 段落建议宽度：50–120 字符，理想约 70 字符（过宽降低阅读效率）。
- 避免极细字重：Regular/Medium/Semibold/Bold 更稳妥。
- 表格与数字：数值建议等宽/Tabular（如有条件可启用字体特性）。

### 2.5 色彩与对比度（Color & Contrast）

**WCAG 量化标准（AA）**

- 普通文本 vs 背景：对比度 ≥ 4.5:1（见 WCAG 1.4.3）
- 大文本（≥24px 或 ≥18.5px bold）vs 背景：对比度 ≥ 3:1（见 WCAG 1.4.3）
- UI 控件边界/图标/焦点环/状态指示 vs 邻接色：对比度 ≥ 3:1（见 WCAG 1.4.11）

**基础色彩 token（建议）**

| Token | 语义 | 示例值（OKLCH） |
|---|---|---|
| `--pc-color-bg` | 页面背景 | `oklch(0.99 0 0)` |
| `--pc-color-surface` | 卡片/面板底色 | `oklch(1 0 0)` |
| `--pc-color-text` | 主文本 | `oklch(0.18 0 0)` |
| `--pc-color-text-muted` | 次文本 | `oklch(0.52 0 0)` |
| `--pc-color-border` | 默认边框 | `oklch(0.9 0 0)` |
| `--pc-color-primary` | 主色（按钮/强调） | `oklch(0.55 0.2 265)` |
| `--pc-color-danger` | 危险/破坏性操作 | `oklch(0.58 0.23 25)` |

### 2.6 间距与尺寸（Spacing & Sizing）

**间距体系：4px 基准（token 化）**

| Token | px |
|---|---:|
| `--pc-space-0` | 0 |
| `--pc-space-1` | 4 |
| `--pc-space-2` | 8 |
| `--pc-space-3` | 12 |
| `--pc-space-4` | 16 |
| `--pc-space-5` | 20 |
| `--pc-space-6` | 24 |
| `--pc-space-7` | 32 |
| `--pc-space-8` | 40 |
| `--pc-space-9` | 48 |
| `--pc-space-10` | 64 |

**控件尺寸（示例）**

| 组件 | 高度（Desktop-S → Desktop-XL） | 横向内边距 | 圆角 |
|---|---:|---:|---:|
| Button | 34 → 36 | 16 | 10 |
| Input | 34 → 36 | 16 | 10 |
| Navbar | 56 | 依据 page margin | - |
| Card padding | 24 | - | 14 |

### 2.7 交互状态（Interaction States）

所有可交互组件至少定义并可视化下列状态：

- Default（默认）
- Hover（悬停）
- Active/Pressed（按下/激活）
- Focus Visible（键盘焦点可见）
- Disabled（禁用）
- Invalid（表单错误）

关键要求：

- 焦点必须“可见且稳定”：推荐 `:focus-visible` + 3px focus ring（满足 1.4.11 的 3:1 对比度需求）。
- 禁用态允许降低对比度，但仍应可辨识（避免完全不可见）。
- 不只靠颜色表达状态：错误/选中建议配合图标、描边、提示文案等（兼顾 1.4.1 Use of Color）。

### 2.8 无障碍（A11y）落地检查清单

- 键盘：所有功能可通过键盘完成（Tab 顺序合理；弹窗关闭后焦点回到触发点）。
- 语义：优先使用原生语义元素（`button/input/a`），必要时再用 ARIA；组件语义与键盘行为参考 APG。
- 对比度：文本≥4.5:1；控件边界/图标/焦点与状态≥3:1。
- 缩放：至少支持浏览器缩放 200% 不裁切核心信息；布局能 reflow，避免横向滚动条。
- 动效：尊重 `prefers-reduced-motion`，避免用动效表达“必须理解的状态”。

## 3) 可复用响应式布局 CSS 代码库（已写入项目）

### 3.1 文件位置与引入方式

- 代码库文件：[pc-ui.css](file:///Users/resty/02-workspace/05-tauri/axon/src/styles/pc-ui.css)
- 已在全局样式中引入：[index.css](file:///Users/resty/02-workspace/05-tauri/axon/src/index.css#L1-L6)

### 3.2 关键能力一览

- 设计 token：`--pc-*`（颜色、字号、间距、圆角、阴影、栅格参数）
- 栅格布局：`.pc-container` + `.pc-grid` + `.pc-col`（通过 CSS 变量控制跨列数，支持断点下变更）
- 常用组件：`.pc-button`（含 primary/danger）、`.pc-input`、`.pc-card`、`.pc-navbar`
- 无障碍支持：`:focus-visible`、`prefers-reduced-motion`、`prefers-contrast` 的基础处理

### 3.3 使用示例（可直接复制）

```html
<div class="pc-app" style="height: 100%;">
  <header class="pc-navbar">
    <div class="pc-navbar__brand">Axon</div>
    <div class="pc-navbar__items">
      <button class="pc-button">Secondary</button>
      <button class="pc-button pc-button--primary">Primary</button>
    </div>
  </header>

  <main class="pc-container" style="padding-block: var(--pc-space-7);">
    <div class="pc-grid">
      <section class="pc-col pc-card" style="--pc-col-span: 8; --pc-col-span-md: 8; --pc-col-span-sm: 12;">
        <div class="pc-card__body pc-stack">
          <h1 class="pc-h1">页面标题</h1>
          <p class="pc-body pc-muted">
            这是一段正文示例，用于验证排版、间距、对比度与 reflow 行为。
          </p>
          <label class="pc-stack" style="gap: var(--pc-space-2);">
            <span class="pc-small">输入框（支持错误态与可见焦点）</span>
            <input class="pc-input" placeholder="请输入内容" />
          </label>
          <div class="pc-row pc-wrap">
            <button class="pc-button pc-button--primary">确认</button>
            <button class="pc-button pc-button--danger">删除</button>
            <button class="pc-button" disabled>禁用</button>
          </div>
        </div>
      </section>

      <aside class="pc-col pc-card" style="--pc-col-span: 4; --pc-col-span-md: 4; --pc-col-span-sm: 12;">
        <div class="pc-card__body pc-stack">
          <h2 class="pc-h2">侧栏</h2>
          <p class="pc-body pc-muted">在 1024–1279px 下建议自动下沉到主内容下方。</p>
        </div>
      </aside>
    </div>
  </main>
</div>
```
